Order: after local C1/D1 and independently reviewed T2.10b. This is one later implementation session, at most nine implementation files. No production deployment is currently authorized. This stage preserves the full T2.10 verification definition.

## Goal

Replace development credit with verified one-use T2.10b entitlement on an HTTPS production route, retain server and local exact checks, enforce atomic global cost caps, and implement the fixed-set recording-derived live evaluation through `pnpm eval`. Produce per-item usage/cost/latency evidence and cumulative budget within the owner's US$5 total; current execution authority remains only US$1.

## Non-goals

No ad SDK, phone UI, subscriptions, training, assistant chat, automatic routing, checker relaxation, budget reset or deployment. BM5 semantic judge calibration/model comparison is separate, but semantic limitations and available owner labels must be reported.

A request above remaining authority fails before provider access. No refunds for potentially billed failures. Production economics/caps are separate owner decisions based on measurements.

```bash
pnpm vitest run tools/summary-backend/worker.test.ts
pnpm eval --mode replay --manifest fixtures/synthetic/t2.10-eval-manifest.json --out /tmp/t2.10c-replay-eval.json
pnpm eval --mode replay --manifest fixtures/synthetic/t2.10-eval-manifest.json --out /tmp/t2.10c-replay-eval-repeat.json

git diff --check
```

Replay is mandatory, costs zero, and deliberately wrong-number/unit/citation output produces exact template fallback. Live is **mandatory once key/config/authority are ready**, consumes the shared cumulative budget and records every item. Reviewer reruns within remaining authority or checks provider-backed usage evidence if rerun would exceed it; Missing live run is NOT RUN and T2.10 cannot close; it is not vehicle hardware-only. No paid invocation is authorized by this spec alone. A genuine provider/endpoint incompatibility is a recorded negative result/blocker, never a silent substitute model.

`pnpm check` includes all backend/app/package tests and TS/lint, plus `cd tools/hil-bridge && uv run ruff check . && uv run pytest`. No Python changes. Authorized deployed HTTPS Worker/key binding evidence and full rewarded phone run remain required external gates, NOT RUN until authorized/setup; local mocks never establish them.
