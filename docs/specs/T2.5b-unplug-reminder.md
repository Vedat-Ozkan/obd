# T2.5b: Unplug-dongle reminder in the Equinox console

## Goal

Show a persistent, readable reminder in the 2024 Equinox console that **disconnecting Bluetooth does not unplug the physical OBD dongle** and that the owner should remove the dongle after a check. The reminder is visible before connecting, while connected, and after a disconnect, so it is still present if a recording, capture, or the T0.9 codes scan stops early. Together with T2.5a's recorded 12 V report section, this fulfills PLAN T2.5's two visible checks: voltage in a report and an app reminder shown.

**Start only after the T0.9 architect/implementer/reviewer chain has stopped editing `apps/mobile/`, then inspect the current `App.tsx` baseline.** T0.9 currently owns the same console, so this sub-spec is intentionally ordered after T2.5a and T0.9. Do not overwrite or revert T0.9's code. If its final UI no longer has the Equinox console or a safe common place for the reminder, return to architecture for a bounded amendment.

## Non-goals

- No voltage read, live threshold, 12 V diagnosis, warning popup, notification, background job, timer, or automatic BLE disconnect.
- No new recording, codes-scan command, battery report screen, PDF/share change, or garage data-model change.
- No native module, dependency, lockfile, or dev-client rebuild. No edit to `packages/obd-core`, `packages/obd-battery`, or T0.9's report logic.

## Interfaces

In `apps/mobile/App.tsx`, keep `EquinoxConsole`'s existing public behavior. Add one visible text block in its main view, near the connection status and before action buttons, using the existing light/dark palette and normal text contrast. Wording may be adjusted for fit, but must convey this exact meaning:

> Unplug the OBD dongle from the car after each check. Disconnecting Bluetooth leaves the dongle powered; it can drain the 12 V battery while the vehicle is off.

It should not be hidden behind a dismissed modal, a connection state, or the scrollable transcript. It stays visible following the normal `teardown` path and unexpected BLE disconnect. Since it is advice tied to the physical dongle, no app state or storage is added.

## Files

- `apps/mobile/App.tsx` — modify one console text block and, only if needed, a small style entry for readability. Follow the T0.9 final baseline. One implementation file.

No new dependencies.
