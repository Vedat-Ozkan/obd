# T2.19: Mobile accessibility to the WCAG 2.2 AA-equivalent checklist

## Goal
Bring `apps/mobile` to the code-side items of the checklist in `docs/ACCESSIBILITY.md` (audit at `8e22d78`): every input named, switch rows and display-only rows exposed with the right role and state, the verdict and section heroes read in full, errors and progress announced once without noise, focus moved on route change, the dongle sheet hiding what is behind it, input borders at 3:1 or more, and 48dp targets without fixed heights. Test-visible outcome: a vitest contrast check over the theme tokens passes in both schemes. User-visible outcome (owner-verified only): TalkBack reads the same information a sighted user sees. Split in three sessions: **Stage A1** (names, labels, contrast, sizes) first, **Stage A2** (switch rows, live regions, focus) second, **Stage A3** (landscape allowed, WCAG 1.3.4) third. Stage B (owner) is hardware only.

## Non-goals
- No React Native Testing Library, Jest, or any new dependency (owner decision 1).
- No ESLint rule or any toolchain change. The local `TextInput` label rule is a separate follow-up, `X-2026-10-23-a11y-lint-rule` (see Follow-ups).
- No "Show as table" chart row, no long-history chart summary, no reduce-motion work (no animation exists), no template edit.
- No `obd-core` / `obd-battery` change. No change to report content, verdict wording, or consent text (only how it is exposed).
- Dev-only `DevelopmentSummary` gets only the live region and link padding in A2, nothing else.

## Design notes
- Focus on route change: `page()` renders the same `TopBar` type across routes, so one `useEffect` keyed on `title` inside `TopBar` and the console's own title view suffices: `AccessibilityInfo.setAccessibilityFocus(findNodeHandle(ref.current))`. Skip the first mount of the garage.
- Live regions: `accessibilityLiveRegion="polite"` on `captureStep`, `betaMessage`, the check `status` text, AI summary; `"assertive"` only on the App `error` text and the picker scan error. The connection details (MTU, UUIDs) move to a sibling `Text` outside the live region. Rationale: `status` is one string for progress and failure; splitting it by failure needs string matching, so it stays polite (open question 4).
- Dongle count: a polite `Text` "N adapters found" in the sheet, rendered from `shown.length`; no `announceForAccessibility`.
- `Hero` / `ListRow` without `onPress`: `View accessible accessibilityLabel`; `ListRow` has no explicit label, so TalkBack reads its title and subtitle.
- Verdict: build the label from the same strings that render (extract the policy sentence into one const used by both the `Text` and the label).
